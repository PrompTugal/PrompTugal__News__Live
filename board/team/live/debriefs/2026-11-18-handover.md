## What I learnt
- Node's fetch reached data.promptugal.news directly in the cloud container; `NODE_USE_ENV_PROXY=1` also works if it ever stops.
- The validator's wording check runs on built pages, so register text with an em dash would fail the build: `clean()` replaces em dashes. A hype word in register text would still fail the build (deliberately: a person looks).
- My first inline-handler check flagged an escaped value inside an attribute; the check now blanks quoted attribute values first. The test fixture proves a real handler is still caught.
- The register's `terms.url` can be null when the operator publishes no terms; such a camera is kept as a link out, never embedded.
