What a meta Content Security Policy cannot do

This site is served by GitHub Pages, which does not let us set response headers. The policy is set in each page's head, which cannot set frame-ancestors or reporting, so another site could frame these pages. Nothing on them acts on a click on your behalf: there are no forms, sign-ins or cookies.
