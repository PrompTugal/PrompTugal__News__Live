API

Everything on this site is first a JSON file, read by GET, with no key. Metadata only: never a frame, snapshot or stream. Our structure and records are CC BY 4.0; each camera stays under its operator's terms, linked in its record.

GETWhat
/api/v1/index.jsonThe catalogue, and when the register was read
/api/v1/cameras.jsonEvery camera: operator, place, view (embed or link), terms, licence, status
/api/v1/cameras/{id}.jsonOne camera with its status history
/api/v1/places/index.jsonEvery place, each with "the camera here" (an embedded camera up at the last check, else any up, else the first), for the weather, travel and place pages
/api/v1/places/{place}.jsonOne place, e.g. faro
/embed/{id}/One camera's player with its credit, for another PrompTugal.news site to frame (view.embed_page in each camera's record, when it can be embedded)
/api/v1/openapi.jsonThe OpenAPI 3.1 description of all of it
/version.jsonThe version of this build

The camera register itself is on data.promptugal.news's API, with its explorer.
